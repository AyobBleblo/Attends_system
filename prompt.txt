### 3.4 Models

**core/models.py**
```python
class Department(models.Model):
    name = models.CharField(max_length=100)
    code = models.CharField(max_length=20, unique=True)

class Semester(models.Model):
    name = models.CharField(max_length=100)
    start_date = models.DateField()
    end_date = models.DateField()
    is_active = models.BooleanField(default=False)
    
    def save(self, *args, **kwargs):
        if self.is_active:
            Semester.objects.exclude(pk=self.pk).update(is_active=False)
        super().save(*args, **kwargs)
```

**accounts/models.py**
```python
class Student(models.Model):
    student_id = models.CharField(max_length=20, unique=True)
    name = models.CharField(max_length=100)

    department = models.ForeignKey(Department, on_delete=models.CASCADE)
```

**courses/models.py**
```python
class Course(models.Model):
    code = models.CharField(max_length=20, unique=True)
    name = models.CharField(max_length=100)
    department = models.ForeignKey(Department, on_delete=models.CASCADE)

class CourseAssignment(models.Model):
    professor = models.ForeignKey(Professor, on_delete=models.CASCADE)
    course = models.ForeignKey(Course, on_delete=models.CASCADE)
    semester = models.ForeignKey(Semester, on_delete=models.CASCADE)
    
    class Meta:
        unique_together = ('professor', 'course', 'semester')
```

**attendance/models.py**
```python
class Enrollment(models.Model):
    student = models.ForeignKey(Student, on_delete=models.CASCADE)
    course = models.ForeignKey(Course, on_delete=models.CASCADE)
    semester = models.ForeignKey(Semester, on_delete=models.CASCADE)
    
    class Meta:
        unique_together = ('student', 'course', 'semester')

class Session(models.Model):
    course = models.ForeignKey(Course, on_delete=models.CASCADE)
    professor = models.ForeignKey(Professor, on_delete=models.CASCADE)
    semester = models.ForeignKey(Semester, on_delete=models.CASCADE)
    date_time = models.DateTimeField(auto_now_add=True)
    qr_token = models.CharField(max_length=100, unique=True)
    qr_expires_at = models.DateTimeField()
    
    def save(self, *args, **kwargs):
        if not self.qr_token:
            self.qr_token = str(uuid.uuid4())
        if not self.qr_expires_at:
            self.qr_expires_at = now() + timedelta(minutes=15)
        super().save(*args, **kwargs)

class Attendance(models.Model):
    STATUS_CHOICES = [('present','Present'),('late','Late'),('absent','Absent')]
    session = models.ForeignKey(Session, on_delete=models.CASCADE)
    student = models.ForeignKey(Student, on_delete=models.CASCADE)
    scanned_at = models.DateTimeField(auto_now_add=True)
    status = models.CharField(max_length=10, choices=STATUS_CHOICES, default='present')
    
    class Meta:
        unique_together = ('session', 'student')
```

### 3.6 API Endpoints (Django REST Framework)

Build these endpoints:
POST   /api/auth/login/              → JWT login (returns access + refresh tokens)
POST   /api/auth/refresh/            → refresh token
GET    /api/departments/             → list departments
GET    /api/semesters/active/        → get active semester
GET    /api/professor/<id>/courses/  → courses assigned to professor this semester
POST   /api/sessions/create/         → create session + generate QR (professor only)
GET    /api/sessions/<id>/qr/        → return QR code as base64 image
POST   /api/attendance/scan/         → student scans QR { student_id, qr_token }
GET    /api/attendance/session/<id>/ → attendance list for a session
GET    /api/attendance/report/       → full report filtered by course/semester/student
GET    /api/students/                → list students
GET    /api/courses/                 → list courses

### 4.3 Pages to build

**Dashboard.jsx** — home page showing:
- Active semester name
- Total students, courses, professors (fetched from API)
- Quick links to all pages

**ProfessorView.jsx** — professor workflow:
- Dropdown to select professor (for testing, no real auth needed)
- Shows assigned courses for active semester
- "Start Session" button for each course
- When clicked: calls POST /api/sessions/create/ and shows QR code (use qrcode.react)
- QR auto-refreshes every 30 seconds (creates new session)
- Shows live attendance count for current session

**StudentScan.jsx** — student workflow:
- Input field for Student ID
- QR scanner using device camera (react-qr-reader)
- OR manual token input for testing (text field + submit button)
- Shows success ✅ or error ❌ message after scan

- Table showing: student name, student_id, session date, status
- Summary: total present / total enrolled / attendance %
