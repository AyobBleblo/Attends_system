Department core

  • id PK, BigAutoField
  • name CharField(200)
  • code CharField(20), unique

Semester core

  • id PK, BigAutoField
  • name CharField(100)
  • start_date DateField
  • end_date DateField
  • is_active BooleanField

Student accounts

  • id PK, BigAutoField
  • student_id CharField(50), unique
  • name CharField(200)
  • department FK → Department

Professor accounts

  • id PK, BigAutoField
  • professor_id CharField(50), unique
  • name CharField(200)
  • department FK → Department

Course courses

  • id PK, BigAutoField
  • code CharField(20), unique
  • name CharField(200)
  • department FK → Department

CourseAssignment courses

  • id PK, BigAutoField
  • professor FK → Professor
  • course FK → Course
  • semester FK → Semester
  • unique_together: (professor, course, semester)

Enrollment attendance

  • id PK, BigAutoField
  • student FK → Student
  • course FK → Course
  • semester FK → Semester
  • unique_together: (student, course, semester)

Session attendance

  • id PK, BigAutoField
  • course FK → Course
  • professor FK → Professor
  • semester FK → Semester
  • date_time DateTimeField
  • qr_token CharField(64), unique
  • qr_expires_at DateTimeField

Attendance attendance

  • id PK, BigAutoField
  • session FK → Session
  • student FK → Student
  • scanned_at DateTimeField, auto
  • status CharField (present/late/absent)
  • unique_together: (session, student)
